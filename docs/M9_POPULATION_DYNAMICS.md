# M9 — Reproduction, Demographic Dynamics, and Ecological Persistence

**Status:** Implemented research baseline; stable, self-sustaining ecology has **not** been demonstrated.

## Research question

Can independently developed policy families function in a shared, evolving ecosystem for long periods without simulator-injected survival, and does allowing real, costly reproduction change the chances of extinction, resource productivity, and recurrent festivals?

## New features

- **Opt-in population dynamics.** `population_dynamics_enabled=true` enables maturation, juvenile limitations, and age-related mortality. `reproduction_enabled=true` enables birth events on top of the same lifecycle rules. Both are off by default to preserve historical experiment behavior and checkpoint tensor shapes.
- **Births cost real energy.** Parents must be mature, well-fed, non-sheltered, outside the species-specific cooldown, and have an unoccupied cardinal neighbor. The parent's energy decreases by the configurable birth cost (default **32**), while the new juvenile receives **22** energy. Reproduction has no free-energy pathway.
- **Species-specific maturation and reproduction cooldowns:**

  | Species | Maturation ticks | Birth cooldown ticks | Soft lifespan threshold | Concurrent cap |
  |---|---:|---:|---:|---:|
  | Farmer | 120 | 150 | 1600 | 24 |
  | Cow | 70 | 90 | 900 | 60 |
  | Nomad | 120 | 150 | 1500 | 18 |
  | Scavenger | 60 | 80 | 750 | 24 |
  | Ravager | 260 | 360 | 2200 | 6 |

  Age beyond the soft lifespan causes progressive health damage rather than immediate death. These numbers are **illustrative**, not calibrated ecological constants. All starting actors begin as mature adults when population dynamics are enabled. Juveniles cannot attack, charge, dash, issue cattle calls, milk cattle, or start/contribute to a festival. Juvenile cows graze but do not produce milk until mature.
- **Hard ceilings for experiment safety.** In addition to concurrent caps, `births_per_species_limit=64` limits new unique birth identities *per species per episode*. Dead identities are not reused. This is a computational constraint and can artificially suppress long-run birth rates; do not mistake a cap-induced plateau for ecological equilibrium.
- **No partner selection or genetic inheritance yet.** M9's single-parent birth is an abstraction, not an attempt at realistic sexual reproduction or a learned mating policy. Offspring inherit group membership and local position but do not inherit separate neural weights. They receive the species-shared policy.
- **Death causes and age.** Outcomes include starvation, attacks, and age-related mortality, with the original `death` event retained for compatibility.
- **Dynamic agent API.** Newborns acquire a fresh stable name such as `cow_birth_0001`. All possible newborn names are predeclared in the PettingZoo adapter; living agents are added/removed without reallocating identities. The same world-state hash can be regenerated by replaying its ordered actions.

## Study commands

Install the CPU-first project and run the reproduction condition:

```bash
python -m pip install -e ".[dev]"
qox population-study --ticks 1200 --seeds 5 --seed 260000 --sample-every 100 \
  --mode scripted --festivals --report runs/m9_scripted_births.json
```

For a proper counterfactual, use the same seeds, tick count, policies, maturity, and aging rules while turning births off:

```bash
qox population-study --ticks 1200 --seeds 5 --seed 260000 --sample-every 100 \
  --mode scripted --festivals --without-births \
  --report runs/m9_scripted_no_births.json
```

Run a random-policy comparison:

```bash
qox population-study --ticks 1200 --seeds 5 --seed 260000 --sample-every 100 \
  --mode random --report runs/m9_random.json
```

For a mixed, **frozen-policy** evaluation (fall back to scripted policies for any omitted role):

```bash
python -m pip install -e ".[dev,ml]"
qox population-study --mode learned --seeds 5 --ticks 1200 \
  --cow-checkpoint path/to/cow.pt \
  --nomad-checkpoint path/to/nomad.pt \
  --scavenger-checkpoint path/to/scavenger.pt \
  --ravager-checkpoint path/to/ravager.pt \
  --farmer-checkpoint path/to/farmer.pt \
  --report runs/m9_frozen_agents.json
```

A festival policy can be supplied separately as `--festival-checkpoint path/to/festival.pt --festivals`; do not also provide an ordinary checkpoint for that festival policy's species. The learned evaluation uses deterministic argmax action selection; it does not update weights or inject rescue actions.

Single-world action replay is also supported:

```bash
qox run --ticks 800 --seed 42 --mode scripted --reproduction --festivals \
  --trace runs/m9_trace.json
qox replay --trace runs/m9_trace.json
```

The optional viewer accepts `--reproduction` without requiring neural dependencies.

## Evaluation output and reporting

JSON reports contain every seed, starting and ending populations, births, deaths, cause counts, juvenile counts, extinction tick per species, festival successes/failures, final state hash, and sampled population/food/celebration time series. Summary entries contain mean, population standard deviation, minimum, and maximum. Keep policies frozen and use distinct training/validation/test seeds for all ML claims.

### Initial deterministic scripted-policy experiments

These are **engineering smoke experiments, not equilibrium evidence**. The following numbers were obtained from the M9 code using three seeds `260000–260002`, 600 ticks, with the same scripted decision rules:

| Condition | Farmers (final mean) | Cows | Nomads | Scavengers | Ravagers |
|---|---:|---:|---:|---:|---:|
| Births enabled, festivals off | 14.0 | 60.0 | 4.67 | 24.0 | 1.0 |
| Births disabled, festivals off (matched aging) | 12.0 | 28.0 | 4.67 | 12.0 | 0.0 |

Cows and scavengers readily reached hard concurrent population caps, while ravagers remained rare and nomads did not reproduce under these conditions. In a separate 600-tick scripted run with births and festivals enabled, there were 16, 19, and 18 successful festivals respectively across the same three seeds. This does **not** show learned cooperation or that resource systems can sustain uncapped populations.

### Longer-run check: aging and finite birth quotas

Two separate scripted, festival-enabled runs at seeds `270000–270001` each lasted **1,200 ticks**. Successful festival counts were **32** and **27**, respectively, but ravagers went extinct in both. The cattle populations fell to **31** and **32**, despite both runs hitting the lifetime limit of **64 cattle births**. Over 80 deaths were age-related per run across species. This exposes a major limitation of the present hard lifetime birth budget: populations can appear healthy at 600 ticks but decline after older generations die. **The ecosystem is not yet demonstrably self-sustaining.**

### Interpretation limits

1. The built-in scripted control contains survival and festival heuristics. Festival outcomes under scripted control are not proof of emergence.
2. Pretrained neural checkpoints were developed in short staged curricula. Freezing them and running them for long horizons tests **generalization**, not an end-to-end retraining of reproduction-aware multi-agent PPO.
3. Birth quotas and concurrent caps can cause artificial saturation; examine birth eligibility, resource availability, and extinction alongside the count plots.
4. The present single-parent model has no breeding pairs, gestation, social inheritance, migration across maps, or carrying capacity derived entirely from calories. Those are appropriate later experiments, not claims of current functionality.
5. Small evaluation samples do not support strong statistical conclusions. Extend to 20+ independent held-out seeds once simulation parameters are calibrated.

## Acceptance and regression testing

- Legacy M8 reproduction-disabled world hashes match at initialization and after scripted steps.
- Resource-funded births never overlap actors, settlements, or impassable terrain.
- Caps, cooldowns, juvenile restrictions, and aging death causes are tested.
- Birth identities survive through PettingZoo transitions without reuse.
- Newborns cannot select actions on their birth tick and inherit group/home IDs.
- Action traces replay deterministically, including birth events and ID counters.
- Frozen checkpoint loading and multi-seed JSON reporting are smoke tested.

## Proposed follow-up experiments

Calibrate ecological resource growth and species cost scales; train reproduction-aware policies on dynamic populations; replace fixed birth limits with adaptive compute budgeting for very long simulations; test joint policy generalization under real cattle-herding, scavenging, predation, and festival pressure. Measure whether cooperation persists **without** scripted partners.
